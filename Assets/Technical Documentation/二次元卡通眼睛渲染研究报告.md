# 二次元卡通眼睛渲染研究报告

> 记录日期：2026-08-10
> 性质：调研报告（网络资料梳理），仅记录，不改动任何代码/资产
> 背景：当前角色所有部位（衣物/面部/头发/眼睛）共用 `GeneralToonyShader.shader` 同一套光照管线。本报告调研业界（米哈游、Unity HDRP、独立游戏社区）对"眼睛"这一特殊部位的处理方式，结论是：**眼睛在业界是被当作独立材质管线处理的**，不应与其它部位共用同一套 ramp 色阶量化光照。

---

## 一、核心结论

1. 眼睛结构特殊：**透明角膜 + 房水（折射层）+ 内凹虹膜** 三层，普通表面没有"折射"这一层。
2. 眼睛的"灵气"来自 **锁定高光** 和 **立体瞳孔（视差/折射）**——这两样恰恰是物理光照与色阶量化做不出来的。
3. 崩坏3（米哈游，贺甲 Unite 2018）、原神、HDRP 的 Eye Shader 全部把眼睛作为**特殊材质**单独处理，与头发各向异性并列，不参与普通 ramp 漫反射。

## 二、业界方案梳理（按工程要点分点）

### 1. 几何建模层：弧面 vs 平面

| 方案 | 做法 | 特点 |
|---|---|---|
| 内凹式 Concave | 瞳孔/虹膜在模型上物理内凹 | 最常见的卡通做法，自带"追眼"视差错觉，侧面不鼓包，最省 |
| 外凸式 Convex | 真实球面眼球 + 视差贴图模拟瞳孔深度 | 高光反射自然（崩坏3 方案） |
| 复合式 Composite | 外层透明角膜（凸）+ 内层虹膜（凹），如《新樱花大战》 | 最精致，开销最大 |

- 业界共识：商业级二游必须用**弧面眼球**；平面贴图只配做 demo/原型。
- 崩坏3 特别说明：普通做法"眼白留空、瞳孔凹陷"侧面自然但**特写不可信**，故用球面 + 折射算法。

### 2. 瞳孔折射（View Refraction）——"有神"的关键

**A. 视差贴图（Parallax，性价比之王）**
- 用高度图模拟虹膜相对角膜的深度，按视线方向偏移虹膜 UV。
- 二次元眼睛深度浅（0.1~0.3），基础视差或陡视差（8~16 层）足够；不建议 POM。
- 性能参考：基础视差每眼 +0.05ms，陡视差 +0.15ms。

**B. 基于物理的折射（崩坏3 / HDRP Eye）**
- 输入：眼球朝向（烘焙法线）、虹膜深度（深度贴图）、房水折射率 IOR≈1.4。
- 按视线折射向量计算 UV 偏移采样虹膜；无折射时眼部侧面"看上去较为奇怪"。
- HDRP 分级：`Eye`（近似）→ `Eye Cinematic`（折射入射光）→ `Eye Cinematic With Caustic`（最贵）。

### 3. 焦散（Caustics）——NPR 特有的"故意不物理"

- 光线穿过角膜+房水聚焦在虹膜上的亮斑。卡通渲染**特意把焦散放在入射光另一侧，入射越平行越明显**（物理正确不是考虑因素）。
- 实现（崩坏3）：
  ```
  backLightDir = reflect(-lightDir, eyeForward)
  causticAtten = pow(DotClamped(backLightDir, normal), 3)   // inverse diffuse 模拟
  caustic = _EyeCausticTint * causticAtten * _LightColor * causticTexture
  ```
- 无焦散的眼睛"暗淡无光缺乏质感"。

### 4. 高光锁定（Highlight Lock）——二次元标志性技术

- 物理高光随视角走、眼球转动高光跟着跑 → 眼睛"呆滞"。二次元正确做法：
  1. **UV 锁定**：高光当"眼球上的固定贴花"，与视角解耦；
  2. **视线反向偏移**：角色向右看时高光在眼球左侧（shader 接收视线方向参数）；
  3. **MatCap**：视图空间法线→UV 采样高光贴图，永远正对相机（Cocos 方案）；
  4. **虚拟眼球法线**（UE_CelLit）：用虚拟球面法线替代网格法线算高光。
- 米哈游级二游几乎全部用高光锁定，不用物理高光。
- 当前 `GeneralToonyShader` 的 `_SpecularFaloff` Blinn-Phong 高光在眼睛上属于"错误示范"。

### 5. 多层叠加结构——眼睛是 5 层，不是 1 层

| 层 | 职责 |
|---|---|
| 眼白（巩膜 Sclera） | 基础色 + 轻微蓝灰阴影；**加自发光兜底**，防止阴影环境变黑（Life Pictures 方案） |
| 虹膜（Iris） | 角色主色；可灰度贴图 × 参数色实现复用 |
| 瞳孔（Pupil） | 深色 + 视差 |
| 高光（Highlight） | UV 锁定硬高光 |
| 眼睑阴影（Eyelid Shadow） | 上方柔和投影（AO） |

- 每层**独立粗糙度/法线**（角膜最光滑、眼白次之、虹膜粗糙）——HDRP Eye 即"角膜+房水"与"巩膜+虹膜"双层材质。
- 角膜缘（Limbus）：虹膜与巩膜间的暗环，Shader 算 mask 生成，侧面观察渐隐。
- **遮蔽（AO）**：骨骼动画的眼睛不能烘 AO，业界做法是**眼睛前放独立 AO 壳模型**（UE4/Cocos 通用），否则眼睛"贴死在脸上"特别出挑。

### 6. 光照待遇差异

- 面部/衣物：ramp 色阶量化（当前 `_DiffuseSteps` 方案）——**眼睛不吃这套**。
- 眼睛：不吃 N·L 漫反射色阶，吃的是 **折射采样 + 锁定高光 + 焦散 + 角膜湿润感（法线）**；阴影环境下眼白要发光兜底。
- 崩坏3 将其归入"特殊材质"单独处理，与头发各向异性并列。

### 7. 配套：透视眼（眼透/飘眉）+ 情绪驱动

- **眼透**：头发要能看到眼睛——Stencil 法（头发 pass `Stencil { Ref 1 Comp NotEqual }`）或 Z 测试双 pass（`ZTest LEqual` + `ZTest GEqual`，Queue Geometry+10）。
- **情绪**：瞳孔大小/虹膜色/高光强度由 MaterialPropertyBlock 驱动，0.3~0.5s 插值过渡；高光可加 flipbook 流光/噪点抖动。

## 三、对本项目的落地建议（对照当前 GeneralToonyShader）

1. **眼睛不应使用当前通用 shader**。当前 `_DiffuseSteps` 色阶量化是给衣物/面部/头发的。
2. **优先级排序（按性价比）**：
   ① 弧面眼球模型（美术侧）→ ② 高光锁定（MatCap 或 UV 锁定，见效最快）→ ③ 虹膜视差折射 → ④ AO 壳 → ⑤ 焦散 → ⑥ 情绪参数。
3. 眼透与描边需要眼睛独立 mesh/渲染顺序配合；与主 shader 现有 `Stencil { Ref 1 Comp Always Pass Replace }`（XRay 用）是两套机制。
