# Miniature Garden

基于什亭之箱（BRP）项目，在 URP 渲染管线下进行重构，目标是完善原有游戏系统、优化项目架构、夯实基础框架并提升代码健壮性。目前主要重构内容如下：

---

## 1. 行为编辑器（Unity 扩展工具）

基于 Timeline 的轨道化角色行为编辑工具，将角色行为表现导出为 ScriptableObject 配置文件，并通过自制的行为解释器高效还原编辑结果。

---

## 2. 基础框架整合与完善

### 资源与 UI 管理
- 为 **AddressableManager** 与 UI 管理模块加入资源依赖绑定功能，避免因忘记卸载资源导致的内存泄漏。
- 完善 **UIManager** 管理能力：
  - 为 `PanelBase` 补充更合理的继承属性与方法。
  - 加入 UIPanel 栈管理，支持按 ESC 键按弹出优先级关闭面板。
  - 新增 `UIWindow` 基类以支持多实例面板窗口，提升使用体验。

### 对象池
- 除通用对象池外，提供 **Mono 池化基类**。静态池使每个继承抽象池化基类的类拥有独立的类池，同时便于各池化类编写自定义的入池/出池逻辑、初始化及数量上限等。
- 该部分参考 **QFramework** 框架进行了功能与结构优化。

### 数据管理
- 改用 **MessagePack** 进行数据持久化，替代原本 BinaryFormatter 方案，消除其带来的数据安全风险。

### 音频管理
- 提供更细致的音频设置管理、音频模块生成及音频单位池化管理。

### VFX 特效管理
- 提供 VFX 特效管理池，高效管理高频使用与弃用的特效单位。

### HSM（层次状态机）
- 引入通用轻量 HSM 模块，便于快速接入和使用。

### 数据插拔式设计
- 提供 `InputProvider` 与 `BlackBoard`，实现数据来源的插拔式设计——数据模块不关心数据来源，只需重写数据输入与处理方法即可获得处理好的数据，结构更加稳定、使用更加便捷。

### 交互模块
- 加入基础交互模块，提供玩家交互的基本方法。

### 计时器修复
- 修复旧版项目中计时器的隐患（计时器队列帧轮询的入队/出队问题），并新增计时器触发次数设置功能，提升基础框架的使用体验。

### 任务系统
- 加入基础任务系统，支持配置多种任务类型。
- > ⚠️ 该模块目前处于开发测试阶段，可能存在缺陷。

---

## 3. 渲染与 Shader 优化

- 编写了表现效果更好的 **URP Cartoon Shader**。
- 修复了 **Blue Archive** 解包模型资源嘴部材质丢失问题，使用 Shader Graph 制作了对应的修复 Shader，使嘴部贴图正常显示。
- 为项目引入更合适的后处理描边效果及全局滤镜。
