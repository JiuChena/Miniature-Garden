# 输入处理模块

## 架构

```
PlayerController.Update()                          ← Player/PlayerController.cs
  └─ _board.ResetFrameData()
  └─ foreach provider in _providers:
       provider.Tick(_board)                       ← 写入黑板
  └─ _moveStrategy.Execute(_board, _cc)            ← 读取黑板执行移动
```

## 文件清单

| 文件 | 路径 | 职责 |
|------|------|------|
| Blackboard.cs | Core Framework/Input/ | 共享输入数据 POCO |
| IInputProvider.cs | Core Framework/Input/ | 输入提供者接口 |
| PlayerInputProvider.cs | Player/Input/ | 读 Input System → 写入黑板 |
| PlayerController.cs | Player/ | 顶层协调器：输入→移动循环 |
| GroundMovement.cs | Player/Movement/ | 地面移动策略（CharacterController） |

## PlayerController 使用方式

1. 在玩家 GameObject 上挂 `CharacterController`
2. 挂 `PlayerController` 脚本
3. 挂 `PlayerInputProvider` 脚本（自动被 Controller 发现）
4. 新建子物体挂 `GroundMovement`，拖入 Controller 的 `groundMovement` 字段
